# Ghost in the Vault

An Obsidian plugin that gives you a Ghostty-styled shell inside Obsidian.

## Installation (BRAT)

1. Install [BRAT](https://github.com/TfTHacker/obsidian42-brat) from Community plugins and enable it.
2. In BRAT's settings, click "Add Beta plugin" and enter `ymkthr/ghost-in-the-vault`.
3. Enable "Ghost in the Vault" under Settings → Community plugins.
